### Ringkasan Poin Kunci:
1. **Anti-Lag 60 FPS Engine**: Default 3D WebGL mode OFF dengan saklar 1-click toggle (`#toggle3DMode`).
2. **Hero Avatar Profile Card**: Kartu profil Hero paling atas di HP untuk impresi pertama yang instan.
3. **Logo Tim Robotika UNY**: Logo Abhinaya UNY & Maestro EVO UNY dengan efek stroke outline putih kontras.
4. **Sertifikat Presisi Puspresnas KRI**: Juara 2 KRTMI 2024 Nasional, Juara 1 Regional 2024, Finalis USM Semarang 2023, & Peserta 2023.
5. **7 CAD Assemblies Autodesk Inventor (.iam)**: Perancangan robotik INESCO 2025, PANCO Seaware, HIMEPA SmartTrash, FKMPI Humanoid, PodComfest, Robot TAMA Seacraft, dan Technocorner UGM Transporter.
